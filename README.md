# Google Gemini AI Overview Blocker (Chrome Extension)
A simple script that removes the AI overview from Google Searches.

## Features
Removes the following from search results:
* AI Overview
* The AI mode tab on the far left (before 'All')
* AI questions and answers from 'People Also Ask'
